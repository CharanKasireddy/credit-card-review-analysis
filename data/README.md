# Data

## Raw data

`raw/All_Reviews.xlsx` is the source workbook from the public Kaggle [Credit Card Reviews](https://www.kaggle.com/datasets/arjunanc/credit-card-reviews) dataset. It is published under CC0.

## Processed data

- `card_ranking.csv` contains review metrics and eligibility results for all 59 cards.
- `top_five_credit_cards.csv` contains the five highest Bayesian scores among cards with at least 20 numeric ratings.
- `current_terms.csv` contains manually verified current issuer inputs for the comparison.

Current terms are not derived from the review dataset and may change. Verify issuer pages before relying on them.
