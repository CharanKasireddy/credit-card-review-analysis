# Contributing

Contributions that improve reproducibility, documentation, source verification, or visualization accessibility are welcome.

1. Create a branch from `main`.
2. Keep current issuer terms separate from review-derived metrics.
3. Document every new external input in `docs/SOURCES.md`.
4. Run `python src/analyze_credit_cards.py` and confirm the expected top five.
5. Open a pull request explaining the analytical change and any limitations.

Do not commit credentials, private application data, or personally identifiable cardholder information.
